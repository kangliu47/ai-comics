# AI Comics

Comics about common enterprise AI problems, told through compact visual analogies. The stories examine adoption, data quality, integration, governance, security, operating capacity, and coordination across organizations.

Start with the [AI Vehicle Comics gallery](ai-vehicle-comics/gallery/README.md), or browse the [series framework and backlog](ai-vehicle-comics/README.md).

All people, organizations, workflows, events, and figures are fictional or illustrative composites. The comics make no claim about a contributor's employer, clients, personal life, or a specific organization's internal practices. Public products may appear as familiar metaphor references.

## Contributing safely

Use roles or approved initials for people. Keep personal and workplace information out of text, images, metadata, and Git history. Read the [public-content privacy rules](AGENTS.md#public-content-privacy-rules) and [release checks](SECURITY.md) before contributing.

Run `python3 scripts/check_public_release.py` before committing. Review creative sources in addition to the gallery: all tracked drafts and prompts are public content. Default credit is **KKLL**; apply contributor initials only to the relevant artwork.

## Organization

Each series keeps its framework, concept backlog, prompt library, reviewed visual assets, and creative decision log. Source prompts and revision reasoning are preserved to make the visual storytelling process reusable.
