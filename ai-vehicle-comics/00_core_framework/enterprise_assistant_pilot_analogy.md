# Enterprise Assistant Pilot Analogy

Use this note when connecting the vehicle series to a hypothetical enterprise assistant rollout.

## Working Analogy

Premium Assistant is a Tesla Model Y with autopilot for daily business use.

It is not a basic company sedan, and it is not a full autonomous work truck. It is a capable business-facing vehicle that can make many daily knowledge-work trips easier, but it still requires route planning, range awareness, and driver judgment.

## Illustrative Pilot Map

| Pilot Concern | Vehicle Analogy | Comic Use |
|---|---|---|
| Premium Assistant license | Model Y key fob | Access is useful only if the driver has a trip worth taking. |
| Integrated Assistant | Company sedan already parked near Microsoft roads | Often the right vehicle for Outlook, Teams, Office, and SharePoint-shaped trips. |
| Token usage | Battery charge, fuel, energy, range | Wasteful context loading burns range before the real trip starts. |
| Prompt/context discipline | Route planning and cargo selection | Bring the right documents, not the entire warehouse. |
| Enterprise data foundations | Trusted maps and navigation data | Autopilot needs accurate destinations, road signs, and current information. |
| System integrations | Roads, bridges, ramps, and gated access | The vehicle cannot reach systems that are not connected or permitted. |
| Pilot group selection | Test drivers with defined routes | A pilot is an experiment, not a VIP parking perk. |
| Enablement | Driver orientation for autopilot | Users need to know where autopilot helps and when to take over. |
| Success metrics | Trip logs and arrival evidence | Measure completed trips, not keys issued. |

## Editorial Position

In a hypothetical enterprise assistant rollout, the strongest critique is not "people want licenses." It is that people are escalating for access before defining:

- which trips require Premium Assistant rather than Integrated Assistant;
- which workflows justify premium token/range usage;
- what context should be loaded and what should be left out;
- what success looks like for the selected pilot group;
- what users must learn before more keys are handed out.

## Core Punchline Pattern

The recurring pilot joke should be:

The organization is fighting for Model Y keys before deciding where anyone is driving, whether the company sedan already makes the trip, how much range the trip costs, or whether the map is trustworthy.
