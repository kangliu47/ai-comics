# Comic 011: Model Y Keys, No Route Plan

Fictional industry scenario. People, organizations, workflows, and figures are illustrative.

## Status

Fictional enterprise assistant pilot scenario

## Core Message

Escalating for Premium Assistant licenses is not a pilot strategy unless users have defined trips, success metrics, token/range expectations, and existing-tool fit boundaries.

## Core Critique

People are asking leaders for premium AI access before deciding what work it should improve, whether Integrated Assistant is already sufficient, how token usage should be managed, or what pilot evidence would justify broader rollout.

## Vehicle Analogy

Premium Assistant is a Tesla Model Y with autopilot for daily business use. The license is the key fob. The pilot intake is the route plan. Tokens are range. Integrated Assistant is the company sedan already parked near Microsoft roads.

## Candidate Four-Panel Flow

1. A leader proudly hands out Model Y key fobs labeled "Premium Assistant Pilot." A banner reads "Selected Users."
2. A pilot intake board shows blank fields: "Destination," "Success Metric," "Existing Tool Alternative," "Token Budget."
3. An eager user sits in the Model Y and asks, "So where are we driving?"
4. Everyone points at the key fob instead of the map. The car remains parked.

## Dialogue And Labels

- Panel 1: Leader: "We got the keys."
- Panel 2: Intake board: "Use case: ___ / existing-tool fit: ___ / Token budget: ___"
- Panel 3: User: "What trip is this for?"
- Panel 4: Caption: "Pilot approved. Route pending."

## Punchline Options

- You got the Model Y. You still need a route.
- A pilot group is not a VIP parking lot.
- Keys first, route later is not a rollout plan.

## Image-Generation Notes

Use the Model Y as a practical business vehicle, not a sci-fi object. The comedy should come from the blank route plan beside the celebrated key fobs. Keep the intake board text large and sparse.

## Open Questions

- Should the bottom kicker mention "pilot" explicitly, or stay as the reusable "You still need a route" line?
- Should "Premium Assistant" appear on the vehicle, key fob, or intake board?
