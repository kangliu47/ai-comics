# Revision Prompt Template

Use this template to improve an existing comic draft, whether text-only or visual.

```text
Revise this comic concept while preserving the core vehicle analogy and minimalist monochrome editorial style.

Current title:
[TITLE]

Current message:
[MESSAGE]

Current four-panel beat:
[PANEL BEAT]

Current punchline:
[PUNCHLINE]

Revision goal:
[EXAMPLE: fewer words, clearer metaphor, sharper final panel, stronger enterprise specificity, less overlap with another comic]

Constraints:
- Keep the comic understandable in 3-5 seconds.
- Preserve dry professional satire.
- Do not over-expand into fictional worldbuilding.
- Keep text short and legible.
- Use the vehicle metaphor to clarify the enterprise AI insight.

Please return:
1. Revised message
2. Revised four-panel beat
3. Dialogue and labels
4. Three punchline options
5. Image-generation notes
6. Risks or open questions
```
