# Visual Style Master Prompt

Use this as the style foundation for future image generation. Customize only the comic-specific content, while preserving the overall look.

## Master Style Prompt

Minimalist black-and-white editorial comic strip, simple stick-figure workplace characters, pen-and-ink line art, hand-drawn outlines, clean white background, light grayscale shading, four-panel layout, expressive but spare faces, witty professional satire, visually clear vehicle metaphor, understated rather than flashy, readable signage and dialogue, modern workplace setting, dry humor, clear panel borders, uncluttered composition.

## Reference Style Master Prompt

Square 2x2 editorial comic page, large hand-lettered title at top, four bordered panels with thick slightly imperfect black borders, black square numbered badges in the upper-left of each panel, one short handwritten narrator caption at the top of each panel, sparse speech bubbles, simple stick-figure workplace characters, slightly more rendered grayscale vehicle, pen-and-ink line art with light gray marker shading, clean white background, dry professional satire, readable signage and labels, centered bottom kicker outside the panels, near-monochrome black-white-gray palette with only tiny muted warning accents if useful.

## Negative Style Guidance

Avoid glossy color, cinematic lighting, photorealism, anime style, superhero style, dense background detail, complex vehicle rendering, tiny unreadable labels, cluttered signage, exaggerated sci-fi worldbuilding, and poster-like composition.

## Text Guidance

- Keep text short.
- Use large, legible lettering.
- Prefer one strong label per object.
- Avoid long dashboard text.
- Use dialogue only when it improves the joke.
- For the reference style, give each panel one narrator caption under roughly 12 words.
- Use exact wording for title, panel captions, speech bubbles, labels, and bottom kicker.
