# Comic Generation Prompt Template

Use this template to generate a visual draft for a specific comic concept.

Before using this template, run the pre-production design check:
- Core message: [ONE-SENTENCE ENTERPRISE AI INSIGHT]
- Causal chain: [BEHAVIOR] causes [CONSEQUENCE]
- Visual contrast: [THING A] versus [THING B]
- Final consequence: [WHY PANEL 4 IS EARNED]
- Clutter risk: [LABELS OR PROPS TO REMOVE]
- Overlap watch: [HOW THIS DIFFERS FROM EXISTING COMICS]

```text
Create a four-panel comic strip in this style:

Minimalist black-and-white editorial comic strip, simple stick-figure workplace characters, pen-and-ink line art, hand-drawn outlines, clean white background, light grayscale shading, expressive but spare faces, witty professional satire, visually clear vehicle metaphor, understated rather than flashy, readable signage and dialogue, modern workplace setting, dry humor, clear panel borders, uncluttered composition.

Comic title:
[TITLE]

Core message:
[ONE-SENTENCE MESSAGE]

Vehicle analogy:
[ANALOGY]

Panel 1:
[VISUAL SETUP]
Text/dialogue: [TEXT]

Panel 2:
[ESCALATION]
Text/dialogue: [TEXT]

Panel 3:
[COMPLICATION]
Text/dialogue: [TEXT]

Panel 4:
[PUNCHLINE VISUAL]
Text/dialogue: [PUNCHLINE]

Important composition notes:
- Make the joke understandable in 3-5 seconds.
- Keep signage and dashboard labels large and readable.
- Use only the labels essential to the joke.
- Keep characters simple, expressive, and workplace-coded.
- When security is relevant, prefer concrete road-safety devices: guardrails, "NO PII" stop signs, "NO SECRETS" or "NO CREDENTIALS" checkpoints, traffic cameras, trip logs, control rooms, and no-retention/no-storage vendor signage.
- Do not make the image glossy, colorful, cinematic, anime-inspired, photorealistic, or visually cluttered.
```

## Reference Style Variant Template

Use this when trying to match the stronger sample style with numbered panels, narrator captions, and a bottom kicker.

```text
Create a square 2x2 editorial comic page in this exact visual style:

Hand-lettered workplace cartoon, black-and-white pen-and-ink line art, clean white background, light gray marker shading, thick slightly imperfect panel borders, simple stick-figure office characters with round heads and expressive faces, a slightly more rendered grayscale vehicle, dry professional satire, readable signage, sparse speech bubbles, uncluttered composition, near-monochrome black-white-gray palette with only tiny muted warning accents if useful.

Overall page layout:
- Large hand-lettered title across the top: "[TITLE]"
- Four equal panels in a 2x2 grid.
- Each panel has a black square number badge in the upper-left corner: "1.", "2.", "3.", "4."
- Each panel has one short handwritten narrator caption near the top.
- Use only the exact text specified below.
- Add a centered bottom kicker below the panels.
```
